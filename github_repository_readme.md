# SciCalc Pro — Scientific Unit Converter & Physics Solver

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Deploy Status](https://img.shields.io/badge/GitHub%20Pages-Live%20Demo-brightgreen)](https://itsnovatvs.github.io/scicalc-pro/)
[![TailwindCSS](https://img.shields.io/badge/Tailwind_CSS-v3.0-06B6D4?logo=tailwindcss)](https://tailwindcss.com/)
[![Built for Science](https://img.shields.io/badge/Category-Scientific%20Tools-0284c7)](https://github.com/ItsNovaTVs/scicalc-pro)

**SciCalc Pro** is a high-precision, single-page web application designed for students, researchers, engineers, and physics enthusiasts. It combines multi-category unit conversions, quantum photon equivalence calculations, physics/chemistry equation solvers, and a searchable fundamental physical constants reference sheet.

## ✨ Features

* **⚡ Real-Time Unit Converter:** Convert between metric, imperial, atomic, and astronomical units instantly across multiple categories.
* **📊 Full Category Breakdown Matrix:** View live conversion output values across all available units in the selected category simultaneously.
* **⚛️ Quantum Photons & Waves Converter:** Direct inter-conversion between photon wavelength ($\text{nm}$), frequency ($\text{Hz}/\text{THz}$), energy ($\text{eV}/\text{J}$), and wavenumber ($\text{cm}^{-1}$).
* **🧮 Interactive Equation Solvers:**
  * **Ideal Gas Law** ($PV = nRT$)
  * **Solution Dilution** ($C_1V_1 = C_2V_2$)
  * **Mass-Energy Equivalence** ($E = mc^2$)
* **📚 Physical Constants Sheet:** Modal sheet featuring fundamental physics constants ($c, h, \hbar, G, N_A, k_B, e, \varepsilon_0, m_e, m_p, R, g_0$).
* **📝 Conversion Log & History:** Save calculations to an exportable log with one-click clipboard copying.
* **⚙️ Notation & Precision Control:** Switch between Standard and Scientific Notation ($1.23 \times 10^4$) with customizable decimal precision (0–12 places).
* **📱 Fully Responsive Dark UI:** Sleek, glassmorphism design built with Tailwind CSS for desktop, tablet, and mobile.

## 🚀 Quick Start & Installation

No build steps, node dependencies, or complex bundlers required! `SciCalc Pro` is built as a single, zero-dependency HTML application.

### Option 1: Live Demo
Access the live deployment on GitHub Pages:
[https://itsnovatvs.github.io/scicalc-pro/](https://itsnovatvs.github.io/scicalc-pro/)

### Option 2: Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/ItsNovaTVs/scicalc-pro.git
   ```
2. Navigate to the project directory:
   ```bash
   cd scicalc-pro
   ```
3. Open `index.html` in any web browser:
   ```bash
   # On macOS
   open index.html

   # On Linux
   xdg-open index.html

   # On Windows
   start index.html
   ```
